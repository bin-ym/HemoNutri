# 🩸 HemoNutri

HemoNutri is a healthcare-focused web and mobile platform designed to connect patients and healthcare providers, offering personalized nutrition guidance, secure doctor-patient communication, and resource management for administrators.  

The platform aims to improve health outcomes by combining **modern UI/UX**, **multi-language support**, and **real-time communication** features.

---

## ✨ Features

### 👩‍⚕️ Patient Features
- Personalized nutrition recommendations.
- Access to educational resources.
- Secure messaging with doctors.

### 🩺 Doctor Features
- Manage patient profiles and consultations.
- Respond to patient messages securely.
- Provide tailored nutrition guidance.

### 🛠 Admin Features
- Manage educational resources.
- Monitor platform activity.
- Handle user account management.

### 🌍 Internationalization (i18next)
- Multi-language support for accessibility.
- Easy translation management.

---

## 🖥️ Tech Stack

**Frontend:**
- React
- Tailwind CSS
- i18next for translations
- Framer Motion (animations)

**Backend:**
- Node.js (Express)
- MongoDB Atlas

**Other Tools:**
- EAS for builds (Expo Application Services)
- Tamagui for theme customization
- Secure API integrations
